# Foona Web 🇿🇦

The high-performance service marketplace platform designed to bridge the gap between Durban's professional artisans and high-demand suburbs.

## 🚀 Vision

Foona is more than a directory; it's a strategic infrastructure built to solve unemployment for South African Pros. By providing real-time demand intelligence and secure financial tools, we empower local hustlers to become scalable businesses.

## 🛠 Features (MVP)

- **Service Heatmaps:** Real-time demand visualization for Durban suburbs (Umhlanga, Westville, Morningside).
- **Instant Payouts:** Fintech-enabled weekly earnings distribution.
- **Trust-First Safety:** Multi-step identity verification for Pros and Customers.
- **Responsive UX:** Premium carousel-driven feature exploration.

## 💻 Tech Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Motion:** Framer Motion
- **Icons:** Lucide-React
- **Deployment:** Vercel

## 🏗 Installation

1. `git clone https://github.com/your-username/Foona-web.git`
2. `npm install`
3. `npm run dev`
